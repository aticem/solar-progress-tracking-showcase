# Solar Construction Progress Trackers

> 🔒 **Showcase** — the source code is private. Walkthrough available on request via [LinkedIn](https://www.linkedin.com/in/acsamiloglu/).

A family of map-based daily progress apps for utility-scale solar sites — one app per work package, all built on the site's own GIS layout.

## Features
- Work packages: DC / LV / MV cable pulling, MV fibre trenching, trenching, mounting tables, PV modules, MC4 connectors, LV boxes & inverters, PV string testing, cable megger testing, punch list
- Click or lasso items on the layout to mark them done
- Daily logs, progress statistics and history
- Chart and Excel export for reports
- Fast canvas rendering for 4,000+ objects with CAD-style scaling text

## Tech stack
React · Vite · Leaflet · Turf.js · Chart.js · ExcelJS
